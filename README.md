# Football xG Lab

獨立實作嘅賽前研究工具。使用 GitHub Pages，計算同 CSV 讀取都喺瀏覽器執行。

- 主隊預期入球 = (主隊主場 xG + 客隊作客 xGA) / 2。客隊反向計。
- 獨立 Poisson 分布推算主和客、總入球和比分。每隊入球枚舉 0 至 50，輸入均值上限為 10。
- 盤口支援總入球及亞洲讓球。四分一盤拆成兩注，贏／走／輸為注額加權。模型打和賠率為 1 + 輸注比例 / 贏注比例。
- 報價超過一小時列為過期。此為 v1 試算設定。模型未校準，盤口結果保留 PASS。
- CSV 回測比較得失球 Poisson 同 xG Poisson，使用同一批賽事。無訓練步驟，主和客 Brier 採三類平方誤差總和，大 2.5 採二元平方誤差。
- CSV 請使用 sample.csv 欄名及純數值資料。hx/ha/ax/aa 係主場／作客 xG、xGA，hgf/hga/agf/aga 係對應場均得失球。每場應只有一行。範例資料為模擬。
- 日期欄檢查只確認截數早過開波。回測數據來源同截數內容需要自行核實。

## 馬會今明賽事

開頁及按 Refresh 時直接向馬會足球端點取資料，以香港日期列出今明兩日仍未開波的賽事。主和客供參考。可將在售大細及亞洲讓球填入試算，使用馬會盤口更新時間。xG、xGA、樣本及統計截數仍由用戶提供。若來源拒絕請求，頁面會顯示錯誤並提供馬會網站連結。

GraphQL 查詢格式參考 [Bobosky2005/hkjc-api](https://github.com/Bobosky2005/hkjc-api)。
